# 搜索与分类控件视觉优化设计

## 范围

本次只调整首页筛选控制区，不修改项目注册配置、卡片结构、收藏、最近访问、健康接口或部署架构。不引入第三方 UI 框架和图标依赖。

## 搜索输入框

搜索框复用 Geek Charge 手机号输入区域的交互语言：

- 控件上方显示中文名称和右侧等宽字段标识 `SEARCH / PROJECTS`。
- 输入区域桌面端高度 78px，移动端高度 68px。
- 默认只显示上下边线，不使用完整矩形输入框。
- 左侧显示橙色搜索图形和竖向分隔线。
- 输入文字使用较大的等宽字体；占位内容为“输入项目名称、标签或描述”。
- 聚焦时上下边线变为橙色，底部橙色扫描线从左向右展开。
- 输入后出现清空按钮；清空后焦点仍停留在搜索框。
- 保留实时筛选，不增加提交按钮或服务端请求。

## 分类选择器

原生 `select` 替换为无依赖的自定义选择器：

- 与搜索框共享标签、边线、字体、颜色和高度体系。
- 收起态显示当前分类、该分类项目数量和橙色 SVG 箭头。
- 展开面板紧贴触发按钮，使用深色实体背景、细边框和轻微阴影。
- 每个选项展示分类名称和项目数量；选中项使用橙色左轨道与对勾。
- 面板以 160ms 淡入、轻微上移恢复的方式出现；箭头同步旋转。
- 点击外部或按 `Escape` 关闭。
- 支持 `ArrowUp`、`ArrowDown` 移动高亮，`Enter` 或空格确认。
- 使用 `aria-expanded`、`aria-controls`、`role=listbox`、`role=option` 和 `aria-selected`，保证键盘可用。

## 布局与响应式

- 桌面端搜索占主要宽度，分类控件固定为适当宽度。
- 900px 以下改为上下排列。
- 640px 以下减少内边距，两个控件保持至少 48px 触摸高度。
- 下拉面板宽度不超过视口，分类文字和数量不能造成横向滚动。

## 动效边界

- 搜索框：焦点扫描线、搜索图标微弱呼吸。
- 分类选择器：箭头旋转、菜单淡入、选项左轨道滑入。
- 搜索结果变化：项目卡片进行短距离错峰淡入，不播放大幅位移动画。
- 当系统启用 `prefers-reduced-motion` 时，关闭扫描和位移动画。

## 行为与状态

- 搜索词和分类继续共同传入现有 `filterProjects` 纯函数。
- 分类默认值为 `all`；刷新页面后无需持久化分类或搜索词。
- 搜索为空和全部分类时显示所有项目。
- 无匹配结果时继续使用现有空状态。

## 测试与验收

- 搜索框实时过滤和清空行为正常。
- 分类菜单鼠标与键盘操作正常。
- 展开、选择、关闭后的 ARIA 状态正确。
- 分类计数与配置数据一致。
- 搜索和分类组合筛选保持正常。
- 390px 视口无页面级横向滚动。
- `prefers-reduced-motion` 下不运行非必要动画。
- 桌面端与移动端视觉检查确认控件与 Geek Charge 的字段交互一致。
